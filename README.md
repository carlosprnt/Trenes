# Quién manda en el tren

Web estática, pensada primero para móvil, que analiza la cúpula directiva de **Renfe** y **Adif**:

- la experiencia previa en gestión y en ferrocarril de cada directivo;
- su vinculación con Óscar Puente o con la política;
- las causas judiciales y los señalamientos de prensa;
- cuánto y cómo cobran;
- una valoración razonada de si estaban cualificados para el puesto.

Corte de datos: 29-10-2026. Cada ficha enlaza a sus fuentes. Los datos se separan en *Judicial*, *Hecho*, *Prensa* y *Política* para respetar la presunción de inocencia.

## Uso

Abre `index.html` en el navegador. No necesita compilación ni dependencias.

Para actualizar los datos, edita `data.js`.
